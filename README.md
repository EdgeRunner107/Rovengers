# ROVENGERS UI V3

이번 버전은 DB 연결 전 UI용 가짜 데이터를 넣은 버전입니다.

## 네비게이션
- 홈: 기존 원페이지
- 멤버: 멤버 카드 UI
- 데이터: 홈의 멤버별 점수 추이로 이동
- 시그니처: 시그니처 갤러리 UI

## 멤버 페이지
- 대표 카드
- Team A / Team B
- LIVE 배지
- 직급
- 프로필 / 공약 / 시그 버튼
- 소개 문구

## 시그니처 페이지
- 전체 / 신규 / 단체 / 가격대 필터
- 검색창
- 5열 썸네일 카드
- 가격/제목/NEW 표시
- 가짜 데이터 30개

## 실행
```bash
npm install
npm run dev
```

나중에 `src/data/mockData.js`를 Supabase 등 DB 조회 결과로 교체하면 됩니다.
